# AI Health - Diabetes Prediction System 🏥

A state-of-the-art web application that leverages machine learning to predict diabetes risk based on various health parameters.

## 🌐 Live Demo
Visit the deployed application: [AI Health Diabetes Predictor](https://ai-health-0gry.onrender.com)

## 🚀 Features

- **Real-time Prediction**: Instant diabetes risk assessment
- **User-friendly Interface**: Clean and intuitive design
- **Comprehensive Input Parameters**:
  - Pregnancies
  - Glucose Level
  - Blood Pressure
  - Skin Thickness
  - Insulin Level
  - BMI (Body Mass Index)
  - Diabetes Pedigree Function
  - Age

## 💻 Technology Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python
- **Machine Learning**: Scikit-learn
- **Deployment**: Render

## 🛠️ Getting Started

1. Clone the repository
```bash
git clone https://github.com/yourusername/AI-HEALTH.git
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Run the application locally
```bash
python app.py
```

## 📊 Model Performance

The prediction model is trained on the Pima Indians Diabetes Dataset and provides accurate risk assessments based on medical parameters.
